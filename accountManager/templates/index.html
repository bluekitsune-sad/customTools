    Import accounts

    JSON or Chrome password CSV. Nothing is uploaded; the file is parsed by the local server.

    Accepted formats

    Chrome password CSV: in Chrome open chrome://password-manager/settings, choose Export passwords, confirm with your Windows account, then select the downloaded .csv file here.

    Account JSON: use the object below, or a bare JSON array of account objects. Passwords are optional.

    Storage: imported passwords are written to vault.json as plaintext in this version.

    {
  "version": 1,
  "accounts": [
    {
      "service": "Example",
      "website": "https://example.com",
      "email": "user@example.com",
      "username": "user",
      "password": "optional",
      "category": "Personal",
      "notes": ""
    }
  ]
}

    Export accounts

    Exports are created locally and downloaded by your browser.

    An export with passwords is a plaintext credential file. Anyone who opens it can read every password. Store it only where you would store your real passwords.

    Backups

    Backups include accounts, profiles, bookmarks, and plaintext credentials.

    Restoring replaces the current data after creating a safety backup of it. Backups are stored in backups/ and contain plaintext passwords.
